# questoes-md/

Coloque aqui os arquivos `.md` gerados pelo projeto Claude "Bahiana", seguindo
o `GUIA_MESTRE_QUESTOES_OBJETIVAS_EBMSP.md`: resumo didático, questões
objetivas (A a E) e gabarito com justificativas.

O conteúdo pedagógico desses arquivos nunca deve ser alterado pelo script de
conversão — apenas diagramado.

Um arquivo de exemplo sintético (`_exemplo_teste.md`) foi incluído apenas
para testar o script de ponta a ponta enquanto não há um `.md` real do
projeto "Bahiana". Ele não tem valor pedagógico e pode ser removido quando
o primeiro `.md` real for adicionado.
